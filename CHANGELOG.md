## [0.1.0] - 2026-11-10

### Added
- Unit conversion and expressions with units on fend-core, with temperature offsets, fuel economy, dB scales and dimension errors.
- CODATA 2022 constants checked against the NIST table, plus maths, earth, astronomy, atmosphere and material tables.
- 138 formula cards in TOML for electronics, physics and maths, each solvable for any one variable.
- Calculator with history, variables and complex numbers, plots with units on the axes, and bases, IEEE-754, bitwise, E-series, colour code and capacitor code tools.
- CLI for all of it, and an agent skill.
